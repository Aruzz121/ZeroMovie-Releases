## Actualizar

Instala la versión 2.4.2 o posterior una vez. Después podrás descargar las siguientes actualizaciones desde ZeroMovie, sin entrar a Drive.

Cuando aparezca el aviso, pulsa **Actualizar**. También puedes comprobarlo en **Apariencia → Buscar actualizaciones**.

- **Android:** pulsa **Instalar actualización** y confirma con el instalador de Android. No desinstales la aplicación.
- **Windows:** pulsa **Reiniciar y actualizar**. El EXE portátil se reemplaza al cerrar y volver a abrir ZeroMovie.

La actualización conserva la sesión y las preferencias. ZeroMovie comprueba la autenticidad y la integridad de los archivos antes de instalarlos.
